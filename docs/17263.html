# 欢迎来到UUSIVC 2026挑战赛 欢迎参加**通用超声图像与视频分析挑战赛2026：B模式和对比增强超声跨多器官分类与分割**。 本挑战赛致力于评估多器官、多模态超声图像和视频分析算法。基准测试涵盖B模式超声图像、对比增强超声(CEUS)视频和心脏超声视频的分类和分割任务。目标是推进超声图像分析中AI模型的泛化能力、鲁棒性和临床适用性。 🧪参与者将通过Codabench平台进行基准测试，利用自动化提交和评估管道，实时排行榜跟踪分类和分割任务的性能表现。 🏆挑战赛结果和获奖者将在[Deep-Breath 2026: 第3届Deep Breast工作坊——乳腺影像诊断和治疗挑战中的AI和影像学](https://deep-breath-miccai.github.io/deepbreath-2026/)期间公布，该工作坊与[MICCAI 2026](https://conferences.miccai.org/2026/en/default.asp)在法国斯特拉斯堡联合举办。 🌐如需了解最新信息、获取指南、数据集访问权限和社区讨论，请访问[UUSIVC2026网站](https://uusivc2026-sudo.github.io/uusivc2026.github.io/)。 📄完整的挑战赛方案可在[此处](https://zenodo.org/records/19729665)获取。 🔗[基准实现](https://github.com/uusivc2026-sudo/UUSIVC-2026-Challenge)。它提供了参与挑战赛的一种可能的实现路径。鼓励参与者探索自己的方法，开发更具竞争力的、最先进的研究算法。 ## 注册 参与者必须通过[谷歌表单](https://docs.google.com/forms/d/e/1FAIpQLSfbO05JF__QkYzL77rdGwoFb3stit-3S5zcbVh4ALYcKjJ7AQ/viewform)注册团队名称并提供相关信息，以获得数据访问权限并提交结果。每个团队最多包括**3名成员**，包括团队负责人。请确保提供准确的**Codabench**用户名，以启用数据访问和提交权限。 ## 数据集 UUSIVC 2026数据集由多个公开超声数据集和与合作医院共同收集的私有数据集组成。 基准测试包括： - B模式超声图像分类 - B模式超声图像分割 - CEUS视频/序列分类 - CEUS视频/帧分割 - 心脏超声视频/帧分割 数据集可通过两个独立的下载来源获取。请选择以下链接之一下载数据集： - [Hugging Face](https://huggingface.co/datasets/WyattH/UUSIVC2026/tree/main) - [百度网盘](https://pan.baidu.com/s/1_8ZDKJdsR1dCsOf7XzG_ew?pwd=usvc) 每个下载来源都包含训练和验证数据。训练集包括输入数据以及相应的样本级标签(用于分类任务)和像素级标注(用于分割任务)。验证集仅包含输入数据，不包含标签或标注。 ## 任务 鼓励参与者开发能够处理多个器官、多种模态和多种任务类型的统一模型或管道。 在线验证基准包括五个任务组： - **image_cls**：超声图像分类 - **ceus_cls**：CEUS视频/序列分类 - **image_seg**：二维超声图像分割 - **ceus_seg**：CEUS视频/帧分割 - **video_seg**：心脏超声视频/帧分割 目标器官和数据集包括乳腺、甲状腺、肝脏、前列腺、阑尾、肾脏、胎儿头部和心脏结构，具体取决于任务类型。 代表性任务包括： - 乳腺病变分类和分割 - 肝病分类 - 阑尾分类 - 甲状腺结节分割 - 肾脏轮廓分割 - 胎儿头部

建议使用单通道灰度PNG。 - 背景应为`0`。 - 前景可以是任何非零值，最好是`255`。 - 如果提交的掩模大小与参考大小不同，评分程序将使用最近邻插值将预测调整为参考大小。 ## CEUS分割预测格式 对于`ceus_seg`，预测应保存为`.npz`文件，位置如下： ```text ceus_seg/<Dataset>/annotations/<annotation_name>.npz ``` 示例： ```text ceus_seg/BreastCEUS/annotations/seg_annotation_00000.npz ceus_seg/LiverCEUS/annotations/seg_annotation_00000.npz ``` 预期的`.npz`文件应包含一个名为`mask`的键： ```python import numpy as np mask = np.zeros((256, 512), dtype=np.uint8) # mask[predicted_foreground > 0] = 255 np.savez("seg_annotation_00000.npz", mask=mask) ``` 掩模要求： - `mask`应为2D数组。 - 背景应为`0`。 - 前景可以是任何非零值，最好是`255`。 ## 视频分割预测格式 对于`video_seg`，预测应保存为`.npz`文件，位置如下： ```text video_seg/<Dataset>/annotations/<annotation_name>.npz ``` 示例：

Scoring Formulas

# 评分公式 该算法将使用以下指标进行评估，所有指标都将用于计算排名。使用指标的实现可以在[这里](https://github.com/uusic2025/challenge/blob/main/evaluation/metrics.py)找到。 ## 分割指标 ### Dice 相似系数 (DSC) Dice 相似系数衡量预测分割掩膜与真实值分割掩膜之间的重叠程度。 ### 归一化表面 Dice (NSD) 归一化表面 Dice 评估预测掩膜与真实值掩膜在容差距离内的边界一致性。 ## 分类指标 ### 曲线下面积 (AUC) 曲线下面积评估分类模型在不同决策阈值下的性能。 ### 准确度 准确度衡量正确分类样本的比例。 ## 任务级评分 验证排行榜分为五个任务组： - **任务1 ImageSeg**：B模式超声图像分割，包括乳腺、胎儿头部、心脏、肾脏、甲状腺和前列腺。 - **任务2 CEUSSeg**：造影超声病灶分割，包括乳腺造影超声、肝脏造影超声、前列腺造影超声和甲状腺造影超声。 - **任务3 VideoSeg**：心脏超声视频/帧分割，包括心脏造影超声。 - **任务4 ImageCls**：B模式超声图像分类，包括阑尾、乳腺、肝脏和前列腺。 - **任务5 CEUSCls**：造影超声视频/序列分类，包括乳腺造影超声、肝脏造影超声、前列腺造影超声和甲状腺造影超声。 对于每个分类数据集： ```text 数据集评分 = 0.5 × 准确度 + 0.5 × AUC ``` 对于每个分割样本或标注帧： ```text 样本/帧评分 = 0.7 × DSC + 0.3 × NSD ``` 每个任务评分是其数据集的样本加权平均值。在线验证排名评分是五个任务评分的等权平均值： ```text 总体评分 = 平均值(任务1, 任务2, 任务3, 任务4, 任务5) ``` ## 在线验证排名 在线验证排行榜仅按性能指标排名。由于验证提交是预测文件，不在统一硬件环境中执行，因此评分中不包含运行时间和GPU显存等效率指标。 对于最终测试阶段，入选团队需提交Docker容器。组织者将在统一硬件上离线运行这些容器，并可能单独报告计算效率。
