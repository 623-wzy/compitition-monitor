Overview

# 第二届高光谱遥感数据处理与应用大赛 ## 赛道三：高光谱高空间分辨率（双高）遥感影像精细分类 地表覆盖分类是遥感领域的核心研究内容，对生态环境保护、农业资源普查、城市可持续规划等具有不可替代的价值。本次比赛聚焦双高（高空间分辨率与高光谱分辨率）遥感影像，不仅具备数百个10nm级光谱分辨率的连续波段，还兼具0.6-5米精细的空间结构信息。本次比赛将打破传统框架，不仅考察算法在严格物理隔离设定下的泛化能力（训练测试场景分离），更考察其在开放环境中对未知类别的识别能力。期望通过本次比赛，推动高光谱精细分类技术向真实落地应用迈出坚实的一步。 **任务：** 在开放环境下，基于高光谱影像对31个已知类别 + 1个"未知类"进行像元级分类。 **数据：** AVIRIS-Classic传感器数据（HyperFree预训练数据集子集），562张影像，224波段，400–2500 nm。 **评价指标：** 宏平均F1分数（主指标），总体精度（辅指标）。
