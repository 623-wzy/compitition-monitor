Overview

# MOSEv2：复杂场景中的视频目标分割更具挑战性的数据集 🏠[主页](https://MOSE.video) 📄[Arxiv](https://arxiv.org/abs/2508.05630) ## 摘要 视频目标分割（VOS）旨在分割视频中指定的目标物体。尽管最先进的方法在DAVIS和YouTube-VOS等现有基准上取得了令人印象深刻的性能（如90+% J&F），但这些数据集主要包含显著、主导和孤立的物体，限制了其在真实场景中的泛化能力。为了推进VOS朝向更现实的环境发展，引入了复杂视频目标分割（MOSEv1）以促进复杂场景中的VOS研究。基于MOSEv1的优势和局限性，我们提出了MOSEv2，这是一个设计用于在真实世界条件下进一步推进VOS方法的明显更具挑战性的数据集。MOSEv2包含5,024个视频和超过701,976个高质量掩码，涵盖200个类别中的10,074个物体。与其前身相比，MOSEv2引入了明显更高的场景复杂性，包括更频繁的物体消失和重新出现、严重的遮挡和拥挤、较小的物体，以及一系列新的挑战，如恶劣天气（如雨、雪、雾）、低光场景（如夜间、水下）、多镜头序列、伪装物体、非物理目标（如阴影、反射）、需要外部知识的场景等。我们在5种不同设置下对20种代表性VOS方法进行了基准测试，观察到性能持续下降。例如，SAM2从MOSEv1上的76.4%下降到MOSEv2上的仅50.9%。我们进一步评估了9种视频目标跟踪方法，发现了类似的性能下降，表明MOSEv2在多个任务中都呈现挑战。这些结果突出表明，尽管在现有数据集上精度很高，但当前的VOS方法在真实世界复杂性面前仍然表现不佳。MOSEv2可在https://MOSE.video获取。 ## BibTeX ``` @article{MOSEv2, title={{MOSEv2}: A More Challenging Dataset for Video Object Segmentation in Complex Scenes}, author={Ding, Henghui and Ying, Kaining and Liu, Chang and He, Shuting and Jiang, Xudong and Jiang, Yu-Gang and Torr, Philip HS and Bai, Song}, journal={arXiv preprint arXiv:2508.05630}, year={2025} } ``` ``` @inproceedings{MOSE, title={{MOSE}: A New Dataset for Video Object Segmentation in Complex Scenes}, author={Ding, Henghui and Liu, Chang and He, Shuting and Jiang, Xudong and Torr, Philip HS and Bai, Song}, booktitle={ICCV}, year={2023} } ``` ``` @article{MeViSv2, title={{MeViS}: A Large-scale Benchmark for Video Segmentation with Motion Expressions}, author={Ding, Henghui and Liu, Chang and He, Shuting, and Ying, Kaining and Jiang, Xudong and Loy, Chen Change and Jiang, Yu-Gang}, journal={IEEE Transactions on Pattern Analysis and Machine Intelligence}, year={2025} } ``` ``` @inproceedings{MeViS, title={{MeViS}: A Large-scale Benchmark for Video Segmentation with Motion Expressions}, author={Ding, Henghui and Liu, Chang and He, Shuting and Jiang, Xudong and Loy, Chen Change}, booktitle={ICCV}, year={2023} } ```
