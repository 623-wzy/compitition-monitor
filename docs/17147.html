竞赛描述

在低空经济蓬勃发展的大背景下，无人机航拍视频已成为国土测绘、应急救援、精准农业等领域的核心数据源。然而，受限于载荷功耗和传输带宽的制约，原始视频常面临分辨率低、细节模糊等瓶颈问题，这严重影响了下游目标识别和场景分析的有效性。视频超分辨率重建作为突破硬件限制、增强数据价值的关键技术，是连接前端数据采集与后端智能应用的重要桥梁。为汇聚全球顶尖算法团队，探索时空信息挖掘的技术边界，攻克复杂动态场景中的细节恢复和纹理增强难题，我们荣幸举办无人机视频超分辨率重建竞赛。 通过此次竞赛，我们旨在激发算法创新，提升真实无人机航拍场景中的高保真时间重建和精细纹理恢复能力——这些场景往往具有低分辨率、高压缩率和运动模糊的特点。该赛事不仅是对计算机视觉与时间信号处理交叉领域技术实力的全面考察，也为全天候智能监控、高精度地理信息更新和自动灾情评估等重大应用提供前瞻性探索。

Evaluation

### 权重分配策略 该方案大幅提升感知度量权重，将LPIPS和DISTS确立为核心指标；采用像素度量作为基本保真度的约束；并使用时间度量保证视频质量的基线。 | 度量类别 | 角色 | 具体度量 | 权重（$W$） | 设计原理 | | :--- | :--- | :--- | :--- | :--- | | **感知质量** | 核心主导 | **LPIPS** | **30%** | 主要度量。深度学习超分辨率中与人类感知对齐度最高的度量。高权重鼓励模型生成丰富的高频纹理并避免过度平滑。 | | | 细节辅助 | DISTS | 20% | 次要度量。结合结构和纹理失真，特别从无人机视角验证复杂地物（如树木、屋顶）的细节，防止伪影。 | | **像素准度** | 基本约束 | PSNR | 15% | 主要度量。虽然权重降低，但仍保持物理基线作用，防止因追求感知质量而产生的严重色移或噪声放大。 | | | 结构辅助 | SSIM | 10% | 次要度量。确保整体结构完整性，保证建筑轮廓清晰且无结构坍塌。 | | **时间一致性** | 稳定性保证 | tLP | 15% | 主要度量。测量特征空间中的时间抖动。闪烁对视频任务是致命的；需要充分权重保证观看舒适度。 | | | 运动验证 | tOF | 10% | 次要度量。在物理光流层面约束运动一致性，防止物体轨迹出现非物理跳跃。 | | **总计** | - | - | **100%** | - | ### 详细计算公式 为公平比较不同量纲的度量，采用**最小-最大归一化**将所有度量映射到$[0, 1]$区间，然后进行加权求和。 #### 第1步：数据收集与极值确定 设参赛团队集合为$N$。对于每个度量$m$（如PSNR、LPIPS）： - 识别所有团队中的最大值$Max_m$和最小值$Min_m$。 - *注：为防止极端异常值扭曲归一化，建议在确定Max/Min前排除前1%和后1%的极端值，或设定理论上下界（如将PSNR上限设为40dB）。* #### 第2步：度量归一化 由于度量方向不同（越高越好与越低越好），必须分别处理： **A. 正向度量（越高越好）：** PSNR、SSIM $$ Score_{i,m} = \frac{Value_{i,m} - Min_m}{Max_m - Min_m} $$ **B. 负向度量（越低越好）：** LPIPS、DISTS、tLP、tOF $$ Score_{i,m} = \frac{Max_m - Value_{i,m}}{Max_m - Min_m} $$ *其中$Score_{i,m}$表示团队$i$在度量$m$上的归一化分数（范围0到1）。* #### 第3步：加权总分计算 $$ TotalScore_i = (0.30 \times S_{LPIPS}) + (0.20 \times S_{DISTS}) + (0.15 \times S_{PSNR}) + (0.10 \times S_{SSIM}) + (0.15 \times S_{tLP}) + (0.10 \times S_{tOF}) $$ 最终分数应四舍五入至四位小数。 ### 阈值条件审核（基于新策略） 为与新的加权系统对齐，建议同步更新参赛阈值。这确保高分团队不仅在感知上表现出色，还符合基本质量标准： | 维度 | 度量 | 推荐阈值 | 说明 | | :--- | :--- | :--- | :--- | | **感知** | LPIPS | $\le 0.250$ | 核心阈值。超过此值表示纹理恢复能力不足。 | | **感知** | DISTS | $\le 0.180$ | 辅助阈值。防止过度优化LPIPS导致的结构坍塌。 | | **像素** | PSNR | $\ge 26.0 \text{ dB}$ | 适度放松（相比纯PSNR导向）。允许为感知质量牺牲少量SNR，但不可过度。 | | **像素** | SSIM | $\ge 0.700$ | 确保基本结构相似度 |
