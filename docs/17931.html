# AI生成图像检测与来源识别 最近的文本到图像生成系统能够生成高度逼真的图像，这些图像越来越难以与真实照片区分。本小型挑战赛的目标是设计并训练一个图像分类网络，以确定图像是**真实图像还是AI生成**，以及对于AI生成的图像，**识别其源模型**。 本挑战赛是**NTU CE7454**课程的一部分。 我们将问题制定为**三类图像分类任务**： * `0` — 真实图像 * `1` — 由**模型A**生成的图像 * `2` — 由**模型B**生成的图像 模型A和模型B的身份和实现细节将不会公开。您的模型应该从提供的训练数据中学习可泛化的视觉特征，而不是依赖于对底层生成系统的知识。 所有发布的图像均为RGB JPEG文件，分辨率为**512 × 512**。 数据集包括： | 分组 | 真实 | 模型A | 模型B | 总计 | 标签已发布？ | | --------- | ---: | ----: | ----: | ----: | ---------- | | 训练集 | 5,000 | 5,000 | 5,000 | 15,000 | 是 | | 开发集 | 300 | 300 | 300 | 900 | 否 | | 测试集 | 500 | 500 | 500 | 1,500 | 否 | 训练图像遵循文件名格式： ```text index_label.jpg ``` 例如： ```text 128_2.jpg ``` 表示训练图像`128`，类别标签为`2`。 开发集和测试集图像遵循格式： ```text index.jpg ``` 其文件名不显示相应的类别标签。开发集和测试集的真实标签由教学团队保管。 开发集可根据教学团队宣布的评估程序用于模型选择。**最终项目排名仅在隐藏测试集上确定**。 --- ### 🚨 重要提交通知 测试集将在以下时间发布： **[2026年10月11日 23:59]** 最终提交截止时间为： **[2026年10月23日 23:59]** 所有时间均遵循课程网站上宣布的时区。 ⚠️ **请勿等到最后一刻才提交。** 参与者有责任确保其提交在截止期限前成功上传并格式正确。 --- ### 评估 最终评估指标是**分类准确率**： ```text 准确率 = 正确分类的测试图像数 / 测试图像总数 ``` 每个测试图像的权重相等。 预测必须为整数标签： ```text {0, 1, 2} ``` 测试集的真实标签**不会**被公开。 解决方案将根据其在隐藏测试集上的准确率进行排名。 --- ### 常见问题 **请在联系教学团队前仔细阅读本部分。谢谢！** * 本项目为**个人项目**。每位学生必须独立开发并提交自己的解决方案。 * 您的模型包含的可训练参数**不超过12,300,000个**。 * 您的模型必须**从零开始训练**。 * **不允许使用预训练权重**，包括ImageNet预训练初始化。 * **不允许使用外部数据**。您只能使用提供的CE7454项目数据集进行训练。 * **不允许**外部图像数据、外部标签、从外部模型获得的伪标签和额外的生成训练图像。 * **不允许模型集成**。 * **不允许测试时模型集成和合并来自多个独立训练模型的预测**。 * **不允许从外部或更大的教师模型进行知识蒸馏**。 * 允许标准数据增强和正则化技术，前提是仅将其应用于提供的训练图像。 * 您不得尝试通过文件名、元数据、手动标注、信息泄露或其他非法方式恢复隐藏的开发或测试标签。
