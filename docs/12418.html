Overview

# PBVS @ CVPR 2026 - 高光谱图像超分辨率（HISR）挑战赛 ## 概述 高光谱图像超分辨率（HISR）超越了传统超分辨率的范畴：高光谱数据包含丰富的波长相关信息，每个波段都编码了特定材料的光谱特征。这意味着HISR必须同时保持空间细节和光谱完整性，确保重建的图像在物理意义上是真实的，而不仅仅是视觉上可信的。 高光谱数据体积大且获取密集，使得全分辨率捕获成本高且速度慢。因此，超分辨率提供了一条强大而实用的途径来减少获取负担，同时实现高质量分析。 本挑战赛在PBVS CVPR 2026研讨会内推出**首个**高光谱超分辨率基准数据集。它专注于实际的低分辨率-高分辨率对偶，在×4超分辨率的受控实验室条件下，使用同一传感器和不同光学器件采集的数据，以隔离空间缩放同时保持光谱一致性。 **本挑战赛的目标是从提供的低分辨率高光谱图像块重建×4实超分辨率高光谱图像。** 每个低分辨率立方体都有一个完美对齐的高分辨率对应体作为真实值，能够精确评估空间恢复和光谱保真度。参与者需要开发能够将低分辨率数据上采样×4倍的方法，同时保持所有波长的光谱一致性。 ## 重要日期 - 2026.01.12 发布训练和验证数据集（输入和输出） - **2026.01.15 测试数据发布（仅输入）** - 2026.01.15 测试阶段服务器上线 - **2026.03.01 测试输出结果提交截止日期** - 2026.03.03 参赛者贡献作品（排名靠前的成果应提供简要的解决方案描述和架构图示；还应共享代码） - **2026.03.06 挑战赛参赛作品论文提交截止日期** - 2026.06.03 PBVS研讨会和挑战赛、结果发布及颁奖典礼（CVPR 2026）

Dataset

# 数据集 ## 描述 本挑战使用的数据集是**HSI Lens数据集版本2**，由PBVS CVPR 2025论文介绍： [Ulrichsen et al., *"A True Hyperspectral Image Super-Resolution Dataset"]( https://openaccess.thecvf.com/content/CVPR2025W/PBVS/html/Ulrichsen_A_True_Hyperspectral_Image_Super_Resolution_Dataset_CVPRW_2025_paper.html) 该数据集提供了**完全配准的低分辨率和高分辨率SWIR高光谱图像对**，使用单个Specim FX17行扫描相机采集（900–1700 nm）。空间分辨率差异纯粹通过**镜头更换**生成，确保光谱内容相同，同时将空间分辨率作为主要挑战。 - 高分辨率图像：**3172 × 640 px**，使用12°镜头采集 - 低分辨率图像：**793 × 160 px**，使用38°镜头采集 - 使用自动焦点指标确保焦点，并通过亚像素配准验证 场景涵盖**光谱丰富且多样的SWIR材料**，包括塑料、木材、电子产品、金属、织物、腐蚀、印刷文字、涂漆表面和各种工业物体。 ## 数据划分 数据集包含**70个配准图像对**，划分如下： - **55**对用于训练 - **10**对用于验证 - **5**对保留用于测试（未发布） 参赛者获得用于训练和验证的低分辨率–高分辨率图像对。 对于**测试集**，仅提供低分辨率输入；高分辨率真值保留用于公平评估。 测试集补丁的低分辨率版本可在此处下载：https://filesender.belnet.be/?s=download&token=237989c4-8c1a-4bd8-b652-49e5dbd90778 ## 可用性 数据集可从存储库"文件"部分下载或通过以下方式获取： **Zenodo DOI：** https://zenodo.org/records/18171738

Evaluation

# 评估指标 提交的结果使用**峰值信噪比（PSNR）**和**光谱角制图仪（SAM）**进行评估，这些指标在隐藏高光谱测试集的20个随机补丁上计算，每个补丁大小为**200×200×224（宽×高×波段）**。排名基于这些指标的综合性能。 测试数据集的低分辨率补丁可在此处下载：https://filesender.belnet.be/?s=download&token=237989c4-8c1a-4bd8-b652-49e5dbd90778 两个指标都是**按波段计算，然后在整个高光谱立方体上求平均**。 ## 评估数据集 评估仅在固定的补丁集合上进行，不在完整图像上进行。 * **选择5个测试场景** * 从每个场景中**提取6个补丁** * 每个补丁的尺寸为**200×200×224**（高×宽×光谱波段） 总共产生30个评估补丁（5个场景×6个补丁）。 **所有指标的计算仅限于这30个补丁。** 完整分辨率的测试图像不用于评估。 ## 峰值信噪比（PSNR） PSNR衡量超分辨率输出与高分辨率真值之间的像素级重建保真度。 较高的PSNR值表示更精确的空间重建。 ## 光谱角制图仪（SAM） SAM通过测量每个像素处重建光谱与真值光谱的光谱向量之间的夹角，量化**光谱相似度**。 较低的SAM值表示材料相关光谱特征保留更好，物理可信度更高。 测试阶段仅提供低分辨率输入；相应的高分辨率真值保持隐藏，仅用于评估。 ## 可重现性和代码可用性（强制性） 为确保透明度、公平性和可重现性，所有参赛团队都必须公开发布完整源代码，最好通过GitHub存储库。 发布的代码必须包含所有必要的组件以重现报告的结果，包括： - 训练和评估脚本 - 模型架构和配置文件 - 数据集加载和预处理步骤 - 环境规范（例如requirements.txt、environment.yml或Docker文件） - 清晰的逐步说明以端到端运行代码 **挑战赛组织者将从头独立训练和评估所有提交的方法，以验证报告的结果。 此验证过程将直接影响最终排名。** **未能提供源代码的团队**，或未包含足够信息以重现其结果的团队，**将被取消参赛资格**。

Submission

# 提交格式 参赛者必须按照下面提供的说明提交预测结果。**不遵守这些规则可能导致取消资格或评分不正确。** ## 打包 - 提交内容必须上传为单个ZIP文件。 - ZIP文件必须包含对应的尺度文件夹（x4）以及生成的SR图像。 ``` submission.zip/ ├── x4/ │ ├── HR_00.h5 │ ├── HR_01.h5 │ ├── HR_02.h5 │ ├── ... ``` 确保.h5文件中只有一个键，该键的名称无关紧要。 数据集必须是3D数组，形状为：(H, W, C)，其中C = #光谱波段数 ## 结果 - 上传后，刷新页面以更新提交状态。 - 评分可能需要长达5分钟。 - 为了调试，单击提交内容，导航到"日志"选项卡，并查看评分日志 > 标准输出
