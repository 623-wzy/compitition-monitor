Participation

# 如何参与 您的提交是一个包含 `submission.py` 的文件夹，该文件定义一个 **benchopt 求解器**，以及您的模型所需的任何权重文件。竞赛服务器仅对其进行**推理评估**：您的模型必须已完全训练好。 ## 协议 继承 `CompetSolver`（来自捆绑的 `compet_core` 包）并实现： - `load_model(self, meta)` — 构建您的模型并从 `meta["weights_dir"]` 加载您随附的权重，将其放在 `meta["device"]` 上。返回一个暴露 `predict(X)` 的对象。 - `predict(X)` 接收已在 `meta["device"]` 上的 torch 批次 `X: (B, C, T)`；期望的输出形状取决于赛道（参见竞赛说明 — 例如类标签 `(B,)`、延迟 `(B,)`、嵌入 `(B, D)` 或关节角度序列 `(B, J, T)`）。 `meta` 还包含 `sfreq, ch_names, chs_info, n_chans, n_times` 和赛道的输出大小（`n_classes` / `n_outputs` / `n_joints`）。 可选地，实现 `fit(self, model, train_loader)` — 它仅在**本地**运行（从不在服务器上），让您通过起始工具包用确切的竞赛数据训练您的模型。 ```python import torch import benchmark_utils # noqa: F401 — 定位 compet_core from compet_core.base_solver import CompetSolver class Solver(CompetSolver): name = "MyModel" requirements = CompetSolver.requirements + ["pip::my-model-pkg"] def load_model(self, meta): model = build_my_model( n_chans=meta["n_chans"], n_times=meta["n_times"], ) state = torch.load(meta["weights_dir"] / "weights.pt", map_location=meta["device"]) model.load_state_dict(state) return model.to(meta["device"]).eval() ``` 您的 `predict` 可以是返回模型的一个方法（纯 PyTorch — 模型内不需要任何 benchopt、neuralset 或 neuralbench 知识）。 ## 本地测试 起始工具包就是基准本身。从竞赛仓库运行（无需安装仓库 — `benchmark_utils` 定位共享的 `compet_core` 包）： ```bash benchopt install tracks/<track> # 求解器/数据集要求 benchopt run tracks/<track> -d Simulated # 零下载烟雾测试 ``` 在上传前迭代提交，将您的 `submission.py` 放入赛道的 `solvers/` 文件夹并运行同一命令；或用摄取程序精确镜像平台： ```bash python codabench/ingestion_program/ingestion.py \ --submission-dir my_submission/ \ --benchmark-dir tracks/<track> --datasets Simulated python codabench/scoring_program/scoring.py \ --prediction-dir output/ --output-dir scores/ ``` 本地在真实数据上训练：`python tools/setup_data.py --track <track>` 一次性下载，然后将您求解器的 `fit` 与 `benchopt run tracks/<track>` 一起使用。 ## 提交 压缩提交文件夹（`submission.py` + 权重）并在*我的提交*选项卡上上传。基准和参考提交位于捆绑的 `solution/` 文件夹中。
