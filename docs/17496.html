# MeViS: 一个用于指代动作表达视频分割的多模态数据集 🏠[主页](https://henghuiding.com/MeViS/) 📄[论文](https://ieeexplore.ieee.org/abstract/document/11130435/) ## 摘要 本文提出了一个大规模多模态数据集，用于指代动作表达视频分割，重点是基于对象动作的语言描述在视频中分割和跟踪目标对象。现有的指代视频分割数据集通常关注显著对象，使用富含静态属性的语言表达，可能允许在单个帧中识别目标对象。这类数据集对视频和语言中动作角色的强调不足。为了探索使用动作表达和动作推理线索进行像素级视频理解的可行性，我们引入了MeViS数据集，包含33,072个人工标注的文本和音频动作表达，涵盖2,006个复杂场景视频中的8,171个对象。我们在MeViS支持的4项任务中对15种现有方法进行了基准测试，包括6种指代视频对象分割(RVOS)方法、3种音频引导视频对象分割(AVOS)方法、2种指代多对象跟踪(RMOT)方法和4种用于新引入的指代动作表达生成(RMEG)任务的视频标题方法。结果表明现有方法在处理动作表达引导的视频理解方面存在弱点和局限。我们进一步分析了挑战，并提出了LMPM++方法用于RVOS/AVOS/RMOT，实现了新的最先进结果。我们的数据集为在复杂视频场景中开发动作表达引导的视频理解算法提供了平台。提议的MeViS数据集和方法的源代码已在https://henghuiding.github.io/MeViS发布。 ## BibTeX ``` @article{MeViSv2, title={{MeViS}: A Multi-Modal Dataset for Referring Motion Expression Video Segmentation}, author={Ding, Henghui and Liu, Chang and He, Shuting and Ying, Kaining and Jiang, Xudong and Loy, Chen Change and Jiang, Yu-Gang}, journal={IEEE Transactions on Pattern Analysis and Machine Intelligence}, year={2025} } ``` ``` @article{MOSEv2, title={{MOSEv2}: A More Challenging Dataset for Video Object Segmentation in Complex Scenes}, author={Ding, Henghui and Ying, Kaining and Liu, Chang and He, Shuting and Jiang, Xudong and Jiang, Yu-Gang and Torr, Philip HS and Bai, Song}, journal={arXiv preprint arXiv:2508.05630}, year={2025} } ``` ``` @inproceedings{MOSE, title={{MOSE}: A New Dataset for Video Object Segmentation in Complex Scenes}, author={Ding, Henghui and Liu, Chang and He, Shuting and Jiang, Xudong and Torr, Philip HS and Bai, Song}, booktitle={ICCV}, year={2023} } ``` ``` @inproceedings{MeViS, title={{MeViS}: A Large-scale Benchmark for Video Segmentation with Motion Expressions}, author={Ding, Henghui and Liu, Chang and He, Shuting and Jiang, Xudong and Loy, Chen Change}, booktitle={ICCV}, year={2023} } ```
