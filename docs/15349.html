Overview

# RAIL-BENCH 轨道：铁路轨道检测 RAIL-BENCH是全球首个铁路领域的感知基准套件。RAIL-BENCH轨道是其五项挑战之一。 以下我们简要介绍RAIL-BENCH轨道数据集、挑战及其评估协议。有关详细信息，请访问我们的[网站](https://www.mrt.kit.edu/railbench/)并查看我们的[RAIL-BENCH工具包](https://github.com/KIT-MRT/RAIL-BENCH_toolkit)。 ## 新闻（2026年8月6日） 我们目前正在进行一些更新和改进。初期阶段已关闭。当我们的更新完成时，新阶段将在8月底开放。 ## 动机 稳健的铁路轨道检测是自动铁路系统中场景理解的基本组成部分。它提供关于用于障碍物检测的感兴趣区域的精确信息。此外，轨道检测与其他地标相结合可用于自我定位。 ## 数据集 RAIL-BENCH轨道包含从火车驾驶员视角拍摄的**2500**张图像。这些图像在德国多种场景（火车站、城市、乡村等）和天气条件（晴天、雨天、雾天等）下以及不同的摄像头设置下进行了记录。所有可见的铁轨都用折线进行了标注。 数据集分为**1500**张训练图像、**500**张验证图像和**500**张测试图像。所有2500张图像以及训练和验证集的真值标注可通过我们的网站访问。测试集的真值标注为了本次挑战的目的被隐藏。 ## 挑战 RAIL-BENCH轨道的任务是检测500张测试图像中的所有铁轨。请参阅**"如何参与"**页面了解有关如何提交结果的详细信息。 提交的结果使用两个指标LineAP和ChamferAP在多个距离阈值处进行评估。对于每个指标，我们报告每个单独阈值处的得分，并计算所有阈值的平均值。然后将两个平均指标得分进行平均以产生用于排名的最终**mAP**（平均精准率）。这个最终mAP—在两个指标和所有阈值上的平均值—是我们挑战的主要排名分数。 有关LineAP和ChamferAP的更多详情，请查看[RAIL-BENCH工具包](https://github.com/KIT-MRT/RAIL-BENCH_toolkit)。 ## 组织者 本基准挑战由卡尔斯鲁厄理工学院（KIT）的Annika Baetz和Dr. Martin Lauer组织，并得到Dr. Martin Köppel（DB InfraGo）、Dr. Philip Neumaier（DB InfraGO）、Pavel Klasek（DZSF）和Seo-Young Ham（DZSF）的支持。如有任何问题或疑虑，请联系Annika Baetz（annika.baetz@kit.edu）。

How to participate

# 如何参与 ## 1. 模型训练 您可以从我们的[网站](https://www.mrt.kit.edu/railbench/)下载训练集、验证集和测试集图像，以及训练集和验证集的真实标签。我们期望您使用训练集训练模型，仅将验证集用于超参数调整、早期停止等。 **在任何情况下都不要在训练和验证期间使用测试图像！** 注意：真实标签注释不仅包含标记导轨的多段线，还包括忽略区域的多边形。我们建议在训练期间移除忽略区域，仅在评估时使用它们。 完成训练后，对500张测试图像运行推理，并按照以下指南提交结果： ## 2. 将预测保存为json文件 将您的预测保存在名为`pred_test.json`的json文件中，格式如下： ```python { 'img_2001_test.png': { 'rails': [<polyline1>, <polyline2>, ...], 'score': [<confidence1>, <confidence2>, ... ] }, 'img_2002_test.png': {...}, 'img_2003_test.png': {...}, ... 'img_2500_test.png': {...}, } ``` 对于每张图像，您需要提供两个列表（`rails`和`score`），其中每一对对应的元素（例如`polyline1`和`confidence1`）代表一条预测的多段线及其模型的相应置信度分数。 ### 多段线 每条多段线由至少2个点的列表表示： ```python [[u1, v1], [u2, v2], ..., [uN, vN]] # u, v是标准图像坐标，u指向右侧，v指向下方 ``` 多段线应该从前景开始并延伸到背景中，即`v1 > vN`。 ### 置信度分数 每个置信度分数应该是0到1之间的值（1表示模型对预测导轨的最大置信度）。 ### 简单示例 一个可能的预测如下所示： ```python { 'img_2001_test.png': { 'rails': [[[100, 2500], [110, 2400], ..., [250, 1000]], [[25, 1490], [120, 1300], ..., [2200, 500]], ...], 'score': [0.71, 0.84, ... ] }, 'img_2002_test.png': {...}, 'img_2003_test.png': {...}, ... 'img_2500_test.png': {...}, } ``` ### 提示： - 确保您的预测缩放至原始图像大小。注意测试图像具有不同的尺寸和宽高比。 - 要检查您的格式，请使用我们的[RAIL-BENCH工具包](https://github.com/KIT-MRT/RAIL-BENCH_toolkit)并使用`check_formatting.py`函数。 ## 3. 提交 将您的`pred_test.json`文件压缩成zip格式，不包含上级目录： ```bash # 创建一个仅包含预测文件的zip（无上级目录） # （使用-j删除任何路径信息，使文件位于zip的根目录） zip -j submission.zip pred_test.json ``` 在**"我的提交 -> 提交"**处提交您的zip文件。 请填写提交页面上的**方法描述字段**，以说明您是否使用了任何额外的训练数据。这包括用于获得任何模型权重的任何数据集，即使您没有亲自对这些数据进行显式训练。

Terms
