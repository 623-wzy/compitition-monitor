Participation

# 如何参与 ## 步骤1：创建Codabench账户 访问 Codabench.org 并点击右上角的"注册"。您需要提供姓名和有效的电子邮件地址。注册完成后，您可以浏览并加入任何公开的基准测试。 ## 步骤2：注册Ego-IRGBench 前往 Ego-IRG Challenge 竞赛页面，点击"我的提交"标签。系统将提示您接受竞赛的条款和条件。由于这是一个启用了自动批准的公开挑战赛，您在接受规则后即可立即参与。 ## 步骤3：下载数据集并准备模型 Ego-IRGBench 数据集托管在 [Hugging Face](https://huggingface.co/datasets/yuki3585/Ego-IEGBench) 上。请根据官方 [ANNEXE 仓库](https://yuggiehk.github.io/annexe/) 中的说明下载并准备数据。该数据集包含超过 2 万张第一人称视角图像，带有 160 万个查询-答案-掩码对，分为训练集、验证集和测试集。 在训练集上训练您的模型，并在测试集上生成预测结果。 ## 步骤4：准备提交的ZIP文件 您的提交必须是单个 ZIP 文件（.zip），结构如下： ```text submission/ ├── results.json # 主要结果文件（必需） ├── mask/ # 预测的像素级定位掩码（必需） │ ├── <query_id>.png │ └── ... ├── depth/ # 预测的深度图（可选） │ └── <image_id>.png └── README.md # 方法摘要（可选） ``` ### results.json 格式 JSON 提交格式由单个 JSON 数组组成，包含测试集中所有图像的每个查询条目。具体而言，JSON 文件应包含一个对象列表，每个对象具有以下属性： - *id* 属性，报告查询的唯一标识符（例如，36331）。 - *image_id* 属性，报告输入的第一人称视角图像的文件名（例如，ZY20210800002_H2_C5_N14_S121_s02_T3_00010.png）。同一图像上的多个查询共享相同的 image_id。 - *query* 属性，报告输入的视觉问答（VQA）查询，从测试集中逐字复制（例如，"Please analyze the interaction in the image and segment the active objects."）。 - *answer_vqa* 属性，报告对 VQA 查询的预测答案（回答子任务）。这应该识别需要分割哪些对象，使用 <MSK>、<MSK_0>、<MSK_1>、... 等占位符（例如，"The mask of the active toy car is <MSK>."）。对于无目标查询，答案应表明未找到合适的结果。 - *answer_caption* 属性，报告预测的交互描述（分析子任务）。这是对图像中所描绘交互的流畅自然语言总结（例如，"A toy car is held by the right hand of the person in this image."）。 - *mask* 属性，报告相对于 mask/ 目录的预测掩码文件路径（例如，"mask/36331.png"）。对于具有 N 个掩码的多目标查询，提供逗号分隔的路径列表或单个合并的掩码文件。对于无目标查询（with_mask: 0），设置为 null。 - *with_mask* 属性，报告掩码存在指示符，为整数（'0' 或 '1'）。如果查询涉及图像中至少一个对象，则为 '1'；否则为 '0'。 results.json 示例： ``` {[ "id": 36331, "image_id": "ZY20210800002_H2_C5_N14_S121_s02_T3_00010.png", "query": "Please analyze the interaction in the image and segment the active objects.", "answer_vqa": "The mask of the active toy car is <MSK>.", "answer_caption": "A toy car is held by the right hand of the person in this image.", "mask": "mask/36331.png", "with_mask": 1] } ``` ### 重要说明 对于具有 N 个掩码的多目标查询，请提供单个合并的掩码文件。 对于无目标查询（with_mask: 0），将 mask 设置为 null。 query 字段必须从测试集中逐字复制——不要改写。 掩码文件必须是放置在 mask/ 目录下的 PNG 图像
