overview

# mer_prefer_stage2：情感偏好 <p>MER-Prefer 是一个新引入的赛道。情感偏好的概念首次在 <a href="https://arxiv.org/abs/2508.01318">EmoPrefer</a> 中提出，该概念针对给定视频预测人类标注者更倾向于哪个情感描述。该任务在训练能够理解人类情感的奖励模型中起着至关重要的作用。</p> <p>我们提供两个训练数据集：<b>EmoPrefer-Data</b>（多数投票标签）和 <b>EmoPrefer-Data-V2</b>（单一标注者标签）。对于测试，我们提供 379 个样本，均采用多数投票标签。</p> <p>有关更多详情，请参阅基准论文：<a href="https://arxiv.org/abs/2604.19417">https://arxiv.org/abs/2604.19417</a></p> <p>官方网站：<a href="https://zeroqiaoba.github.io/MER-Challenge/">https://zeroqiaoba.github.io/MER-Challenge/</a></p> ## 提交格式 <p>结果文件必须命名为 <code>answer.csv</code>，包含以下列：</p> <ul> <li><code>name</code>：样本标识符</li> <li><code>a1</code>：第一个情感描述（文本）</li> <li><code>a2</code>：第二个情感描述（文本）</li> <li><code>preference</code>：首选描述 — 必须恰好是 <code>a1</code> 或 <code>a2</code></li> </ul> <p>将 <code>answer.csv</code> 压缩为 <code>answer.zip</code> 并通过 Codabench 提交。</p>

evaluation

# 评估 在MER-Prefer中，我们使用**加权F1分数（WAF）**作为主要评估指标，**准确率（ACC）**作为次要评估指标进行二分类偏好分类评估。 对于每个样本，提交内容必须预测人工标注者更倾向于描述`a1`还是`a2`。该预测与地面真实偏好标签进行比较评估。 仅评估在地面真实集合中存在`(name, a1, a2)`元组的样本。 详见基线论文：<a href="https://arxiv.org/abs/2604.19417">https://arxiv.org/abs/2604.19417</a> 官方网站：<a href="https://zeroqiaoba.github.io/MER-Challenge/">https://zeroqiaoba.github.io/MER-Challenge/</a>
