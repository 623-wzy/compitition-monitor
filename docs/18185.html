Overview

# RoboWorld 2026 赛道1：WorldNav 欢迎来到WorldNav，这是RoboWorld 2026的语言条件视觉导航赛道，隶属于NeurIPS 2026的RoboPAD研讨会。 智能体接收一张初始的自我中心RGB图像和一条自然语言指令。它必须在没有目标图像、初始数值姿态或来自环境的进一步观测的情况下，预测完整的导航动作序列。欢迎使用世界模型、视觉-语言-动作模型以及纯策略方法。 ## 任务定义 提交可变长度的`[dx, dy, dyaw]`动作序列。`dx`表示前向运动，`dy`表示智能体当前局部坐标系中的左向运动；`dyaw`以弧度改变朝向。 私有评估器使用记录的初始姿态来重建预测路径。测试参与者仅接收初始图像和指令，而不接收姿态、目标、参考轨迹或参考动作序列。 ## 阶段 第1阶段用于开发和验证。最终排名和奖项完全基于第2阶段；阶段分数不合并。提交前请在CodaBench上查看当前阶段日期。 | 阶段 | &emsp; Submission & Evaluation

# 提交与评估 将预测的动作序列提交至ZIP压缩包，仅使用每个片段的初始RGB图像和指令。 ## 动作格式 每个动作为[dx, dy, dyaw]：前向位移、智能体**当前局部坐标系**中的左向位移，以及偏航角更新（弧度制）。序列长度可不同；JSON列表标记轨迹结束。 限制：每个片段最多64个动作；单次动作的hypot(dx,dy) ≤ 2.46数据集坐标单位且|dyaw| ≤ 6.29弧度（在[−π, π)范围内对2π取模计算）。 ## ZIP文件结构 将所需的JSON文件置于压缩包根目录。可下载的示例ZIP展示了文件结构和第一阶段片段ID；替换其中的示例动作。 | 阶段 |   | 所需文件 | | :-- | :--: | :-- | | 第一阶段 |   | val_seen.json, val_unseen.json | | 第二阶段 |   | test.json | ### JSON模式 每个文件包含数据集划分和片段。每个阶段的episode_id必须且只能出现一次，附带动作列表： { "split": "val_unseen", "episodes": [ { "episode_id": "20210826_40_0001_02_0", "actions": [[0.25, 0.0, 0.0], [0.0, 0.0, 0.15], [0.12, -0.05, 0.0]] } ] } 此简化示例并非完整提交。 ## 评估指标 两个保真度指标范围为0到1。五种计算方法参见[demonstration.py](https://github.com/F1y1113/worldnav-challenge/blob/main/demonstration.py)。 | 指标 |   | 方向 |   | 含义 | | :-- | :--: | :-- | :--: | :-- | | **成功率 (SR)** |   | 越高越好 |   | 满足最终位置成功标准的比例。 | | **绝对轨迹误差 (ATE)** |   | 越低越好 |   | 相对于参考轨迹的位置误差。 | | **相对位姿误差 (RPE)** |   | 越低越好 |   | 连续位姿之间的相对平移误差。 | | **全路径保真度** |   | 越高越好 |   | 与完整有序记录路径的一致性，包括对不必要移动的惩罚。 | | **航向与转向保真度** |   | 越高越好 |   | 移动时朝向以及转向方向、位置和幅度的一致性。 | ## 综合得分 首先对每个片段进行评分，然后取平均值： Score = (100/N) × Σ_i { FullRouteFidelity_i × (1 + HeadingTurnFidelity_i)/2 × [0.70 + 0.10 SR_i + 0.10/(1+ATE_i) + 0.10/(1+RPE_i)] } SR_i为二元成功标志；ATE_i和RPE_i为每个片段在数据集坐标单位下的误差。得分取各片段贡献的平均值。 第一阶段按`(Score_val_seen + Score_val_unseen) / 2`排名，两个划分权重相等。两个划分的文件都必须提交；缺少任一文件的提交将被拒绝。两个划分的得分均会显示。第二阶段按测试集得分排名。
