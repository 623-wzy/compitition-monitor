Description

# 🩺 # **OncoSegment: 乳腺肿瘤分割挑战赛** # 💡 ## **该问题的研究价值** 乳腺癌仍是全球女性死亡的主要原因之一。通过超声进行早期和准确检测至关重要，但解读这些图像却 notoriously 困难。超声图像存在"散斑噪声"且对比度低。正如等离子体物理模拟中的"团块"一样，超声中的肿瘤呈间歇性分布，边界不规则，且容易与正常健康组织混淆。本挑战要求你开发能够精确勾勒肿瘤边界的人工智能，该任务可直接辅助放射科医生进行活检规划与治疗。 # 📊 ## **数据** 数据集源自乳腺超声图像（BUSI）数据集，研究对象为25-75岁女性。包含高质量的PNG扫描图像，标准分辨率约为500×500像素。 数据集构成： 良性：通常为椭圆形或圆形、边缘光滑的肿瘤。 恶性：癌性肿瘤，通常以"毛刺状"（spiculated）或侵入周围组织的不规则边界为特征。 正常：无肿瘤的扫描图像（用于测试模型避免假阳性的能力）。 入门套件包含： train_images：一系列显示乳腺组织的PIL图像（灰度）。 train_masks：二值掩膜，其中1代表肿瘤，0代表背景。 train_labels：元数据，用于识别肿瘤为良性或恶性。 test_images：需要预测掩膜的图像。 # 📏 ## **评估指标：精确度测量** 在医学影像中，简单的"框选"是不够的。我们需要确切知道哪些像素是癌性的。我们采用两种互补的重叠指标： 1. 主要指标：Dice系数（F1分数） Dice系数是医学分割领域的黄金标准。计算方法为预测与真实值重叠区域面积的两倍，除以预测与真实值的总像素数。 $$Dice = \frac{2 \times |P \cap G|}{|P| + |G|}$$ 原因：该指标对掩膜内部的"充实度"高度敏感，能够奖励形状完全精确的模型。 2. 次要指标：Jaccard指数（IoU） Jaccard指数是交集面积除以并集面积。 $$Jaccard = \frac{|P \cap G|}{|P \cup G|}$$ 原因： 相比Dice，它对微小错误更为"严苛"。 有助于在排行榜上打破平局，突出显示具有最少杂散假阳性像素的模型。
