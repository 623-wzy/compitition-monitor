Overview

<h1 align="center"><b>NTIRE 2026: 3D内容超分辨率挑战赛</b></h1> <h2>重要日期</h2> <ul> <li>2026-01-15: 发布训练和验证数据;<br></li> <li>2026-01-30: 验证服务器上线;<br></li> <li>2026-03-10: 最终测试数据发布，验证服务器关闭;<br></li> <li>2026-03-17: 测试结果提交截止日期;<br></li> <li>2026-03-17: 技术文档/代码/模型提交截止日期;<br></li> <li>2026-03-19: 向参赛者发布测试初步分数;<br></li> <li>2026-03-22: 挑战赛论文提交截止日期;<br></li> <li>2026-03-24: 论文录用通知;<br></li> <li>2026-04-08: 最终定稿;<br></li> <li>2026-06-18 (待定): 研讨会日期;<br><br></li> </ul> <h2>引言</h2> 超越传统的图像和视频，3D内容凭借能够提供场景的外观和几何信息而获得了极大的普及。近年来，由于3D生成和重建技术的进步，3D内容呈现出指数级增长。然而，当前的3D生成模型仍然存在质量相对较低的问题。对于3D重建，由于现实世界中存在各种约束，观测到的多视图图像通常分辨率较低，这最终导致重建的3D内容质量下降。在AR/VR等应用中，迫切需要提高这些3D内容的分辨率，以提供沉浸式体验并帮助解析现实世界。<br> 近年来，图像超分辨率(SR)在提升图像视觉质量方面取得了显著进展。为了增强3D内容的质量，一种直接的方法是使用现成的图像SR模型对渲染图像进行超分辨率处理。然而，这种方法忽略了几何信息与外观信息之间的紧密耦合关系，导致多视图不一致和闪烁伪影。<br> 在本次挑战赛中，我们旨在建立一个3D内容超分辨率的基准。我们希望着重提出3D内容超分辨率所面临的特定挑战和研究问题。我们希望本次挑战赛能够激励学术界探索底层视觉与3D视觉的交叉领域，并最终推动AR/VR等新兴应用的技术进步。<br><br> <h2>挑战赛描述</h2> <a href="https://www.cvlai.net/ntire/2026/">第八届NTIRE: 图像恢复与增强新趋势研讨会</a>将于2026年6月与CVPR 2026联合举行。<br> 本次挑战赛的目标是从低分辨率(LR)对应物重建高分辨率(HR) 3D内容。在开发阶段，验证集将被发布。参赛者可以通过将结果提交到验证服务器来在验证集上评估他们的模型。具体来说，在给定相机内参和外参的条件下渲染超分辨率图像，然后将其提交到服务器进行在线评估。 在测试阶段，测试集将被发布，其中仅包含低分辨率3D内容。挑战赛参赛者应将训练好的模型应用于低分辨率3D内容以生成超分辨率结果。然后，这些结果将被提交到服务器，由组织者进行评估。<br> 本次挑战赛有两个赛道： <ul> <li><a href="https://www.codabench.org/competitions/12891/">赛道1: 双三次退化</a><br></li> 本赛道的目标是在双三次退化（Matlab的$imresize$函数双三次模式）条件下获得超分辨率3D内容。 <li><a href="https://www.codabench.org/competitions/12894/">赛道2: 真实退化</a><br></li> 本赛道的目标是在真实退化条件下获得超分辨率3D内容。 </ul> <h2>组织者</h2> <ul> <li><a href="https://longguangwang.github.io/">王龙光</a> (wanglg9@mail.sysu.edu.cn), 中山大学<br></li> <li><a href="http://yulanguo.me/">郭裕兰</a> (guoyulan@sysu.edu.cn), 中山大学<br></li> </ul>

Data
