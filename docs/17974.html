ID: 17974 创建者: sylvchev 创建时间: 2026-09-05 参与人数: 287 提交次数: 116 在 Codabench 查看 ↗

竞赛描述

通过在冻结的DINOv2-giant空间中对候选样本排序，从单段脑电信号中解码被观看的自然图像。参赛提交内容包括训练好的模型（含代码和权重）。平台在未见过的图像上运行纯推理评估，并按Top-5检索准确率排名。由Benchopt和NeuralBench提供支持。

Submission Guide

# 如何提交你的模型 ## 提交规则 通过**我的提交**标签页上传一个**完全训练的模型ZIP文件**。 Codabench会将解压后的文件以只读方式挂载，在推理模式下运行模型，计算赛道指标，并发布分数。它不会训练你的模型。 你典型的`my_submission.zip`包含： ```text my_submission.zip ├── submission.py # 必需：所有Python推理代码 ├── weights.pt # 训练参数，任何名称或格式均可 └── ... # 可选的非Python产物，如config.json ``` - 将所有文件放在**ZIP根目录**。 - `submission.py`必须包含`class Solver(CompetSolver)`、模型架构、模型特定的预处理以及所有Python推理代码。不支持额外的Python模块。详见下文。 - 包含模型所需的每个权重和可选的非Python产物。在`submission.py`中从`meta["submission_dir"]`读取它们。 评估期间不会安装任何东西，因此`submission.py`只能导入工作镜像已携带的内容——`torch`以及固定在[`requirements.txt`](https://github.com/neural-interfaces26/2026-competition/blob/main/requirements.txt)中的其他软件栈。在`load_model`和`predict`期间，不要训练，不要下载竞赛数据，也不要写入提交目录。 **提交存储限制。** Codabench为每个配置文件提供15 GB的提交存储空间，在所有赛道和上传之间共享；不是每个ZIP单独的15 GB限制。这使得15 GB成为一次提交的理论最大值，但实际限制是你配置文件中剩余的空间。如有需要，在**配置文件 → 资源**下删除未使用的已归档提交。显示在排行榜上的提交无法删除。 --- ## 五步提交 1. **在本地训练和验证**，使用可选的NeuralBench启动套件、直接通过Benchopt或使用你自己的流程。保存训练好的权重。如果你的Benchopt求解器实现了下文描述的可选`fit`和`save_model`方法，其训练运行会将求解器和权重写入一个准备上传的提交文件夹中。 2. **创建`submission.py`**，遵循下文合约。 3. **创建ZIP。**对于上述示例，运行： ```bash zip -j my_submission.zip submission.py weights.pt ``` 添加`config.json`或模型需要的任何其他非Python产物。 4. **先在本地检查。**上传失败仍会消耗你当日提交次数中的一次，而且大多数失败会在几秒钟内被发现： ```bash cp my_submission/submission.py tracks/<track>/solvers/my_submission.py COMPET_SUBMISSION_DIR="$PWD/my_submission" \ benchopt run tracks/<track> -d Simulated -s MyModel ``` 有关这涵盖和不涵盖的内容，请参阅[在本地测试你的提交](#test-your-submission-locally)。 5. **上传。**在**我的提交**中，选择活跃阶段，上传ZIP，并等待**完成**。如果失败，从摄取日志中的第一个错误开始排查。 --- ## `submission.py`合约 在`submission.py`中，你编写普通的Python或PyTorch代码。Benchopt提供评估包装器，但你不需要了解其内部机制。Codabench期望两个组件： 1. 一个命名了的`class Solver(CompetSolver)`，实现`load_model(meta)`。 2. 一个由`load_model`返回并暴露`predict(X)`的模型。 ### 合约1：`class Solver(CompetSolver)`加载训练好的模型 在`class Solver(CompetSolver)`中，**`load_model(self, meta) -> model`是必需的**。它重建训练好的架构，加载随附的权重，将模型移动到评估设备，并以评估模式返回： ```python import torch from benchmark_utils.base_solver import CompetSolver class Solver(CompetSolver): name = "MyModel" def load_model(self, meta): # MyModel必须在此submission.py文件中定义或从依赖项导入。 ```
