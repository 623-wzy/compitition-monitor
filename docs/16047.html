Overview

# UrbanTwin Sim2Real LiDAR 挑战赛 — LUMPI 赛道 *第6届DriveX工作坊 @ ECCV 2026 的挑战赛道 — [drivex-workshop.github.io/eccv2026](https://drivex-workshop.github.io/eccv2026)* 路边LiDAR感知在智能交通系统中的发展受到大规模、标注完善的真实数据集成本高且稀缺的制约。本挑战赛提出：能否使合成LiDAR数据达到足够的真实性，使得在其上训练的深度学习模型能够泛化到真实LiDAR帧？ 为此，本挑战赛要求参与者针对**LUMPI**分布生成自己的合成LiDAR数据、在该数据上训练目标检测器，并在真实的保留测试帧上提交检测结果。评分基于：(1) 其合成帧与真实帧的分布接近程度，以及 (2) 仅在合成数据上训练的检测器在真实帧上的性能。 ## 参与者参考资源 为支持寻求文档化起点的参与者，我们公开提供了一套完整的参考管道，涵盖合成方法、经验分析、即用型合成数据集和开源LiDAR数据处理与可视化软件。这些资料作为参考方向提供，而非强制要求。 合成管道在《[UrbanTwin: 为Sim2Real LiDAR感知与评估构建高保真数字孪生体](https://arxiv.org/pdf/2509.02903)》(arXiv预印本)中描述，更深入的经验分析包括本挑战赛所采用的分布真实性指标，详见《[高保真数字孪生体缩小LiDAR基础智能交通感知中的Sim2Real差距](https://scholar.google.com/scholar?oi=bibs&cluster=6844982498826808010&btnI=1&hl=en)》(IEEE T-ITS, 2026)。 使用该管道生成的合成LiDAR数据集发布在《[UrbanTwin: 合成路边LiDAR数据集](https://ieeexplore.ieee.org/iel8/8784355/8957420/11357520.pdf)》(IEEE OJ-ITS, 2026)中，可从[哈佛数据库](https://dataverse.harvard.edu/dataverse/ucf-ut)下载。每个数据集包含**10K帧**，跨越**6个目标类别**，用于**检测、跟踪和分割任务**，与本挑战赛使用的多类评估完全兼容；论文中的经验分析既包括分布真实性指标，也包括单类3D目标检测研究作为概念验证。对于端到端LiDAR处理，我们还提供了[LiGuard框架](https://ieeexplore.ieee.org/document/11498694)(IEEE T-IV, 2026)以及更加软件聚焦的简明读物《[开源软件期刊](https://joss.theoj.org/papers/10.21105/joss.06751.pdf)》。 ## 你将执行的步骤 1. 下载公开真实**LUMPI**数据集和发布的检测测试点云(50个真实帧，无标签)。 2. 使用任何方法生成合成LiDAR帧 — 模拟(CARLA、LGSVL、自定义)、生成模型(扩散、GANs、流基模型)、混合管道或其他任何方法。 3. 在**仅你的合成数据**上训练3D目标检测器(任何架构)。 4. 提交： - 50个你的合成LiDAR帧 - 你的检测器在50个发布测试点云上的预测结果 - 一份签署的诚信声明 ## 评分概览 综合评分 = `0.6 × 归一化3D mAP` + `0.4 × 归一化真实性`，其中3D mAP在本赛道定义的**8个**目标类别(*行人、汽车、自行车、摩托车、公交车、卡车、货车、未知*)上平均，真实性平均归一化的Chamfer距离、MMD、EMD和Fr

# 评估协议 <p> 计算两个分数并将其合并为单一的<em>综合</em>分数 以确定排行榜排名。 </p> <h2>1. 分布真实性</h2> <p>聚合：</p> <ol> <li>将50个提交的合成帧连接成一个集合 <code>S_syn</code>；将50个保留的真实参考帧 连接成<code>S_real</code>。</li> <li>将两者都掩盖到点云范围 <code>[-40, -40, -5, 40, 40, 5]</code>。</li> <li>以种子1234均匀随机子采样到<strong>每侧N = 10,000个点</strong> （启动工具包中的本地评估器使用相同种子）。</li> <li>在整个10,000点集上计算<strong>一个</strong>CD、MMD、EMD和FPD。</li> </ol> <h3>1a. 倒角距离（CD）</h3> <pre> CD(P, Q) = (1/|P|) Σ_{p ∈ P} min_{q ∈ Q} ||p - q||² + (1/|Q|) Σ_{q ∈ Q} min_{p ∈ P} ||p - q||² </pre> <p>平方L2最近邻成本；对称的。数值越小越好。</p> <h3>1b. 最大均值差异（MMD）</h3> <pre> MMD²(X, Y) = E[k(x, x')] + E[k(y, y')] - 2 E[k(x, y)], k(a, b) = exp(-γ ||a - b||²) </pre> <p> 无偏估计量（非对角线）。带宽<code>γ</code>通过1000点联合子样本上的中值启发式设置 （<code>γ = 1 / (2 · median ||x - y||²)</code>），以便核在LiDAR空间尺度上不饱和。数值越小越好。 </p> <h3>1c. 地球移动距离（EMD）</h3> <pre> EMD(X, Y) = √ ( min_{T ∈ Π(X, Y)} Σ_{i,j} T_{ij} · ||x_i - y_j|| ) </pre> <p> Wasserstein-1距离，欧几里得地面成本，通过网络单纯形精确求解（POT的<code>ot.emd2</code>）。以米为单位报告。数值越小越好。 </p> <h3>1d. 弗雷歇点云距离（FPD）</h3> <pre> FPD = ||μ_X - μ_Y||² + Tr(Σ_X + Σ_Y - 2 (Σ_X · Σ_Y)^{1/2}) </pre> <p> FID风格：对每个集合的点拟合3变量高斯分布，计算高斯分布之间的2-Wasserstein距离。数值越小越好。 </p> <h2>2. 3D物体检测</h2> <p> 参与者在50个真实LiDAR帧上提交检测结果（<code>predictions.json</code>），这些帧的真实标注被保留。我们在<strong>为该赛道定义的8个物体类别</strong>上计算平均精度 （<em>行人、汽车、自行车、摩托车、公交车、卡车、货车、未知</em>），IoU阈值为0.5（主要）和0.7 （次要）。报告每个类别的AP，以及<strong>各类别的平均AP （mAP）</strong>是排行榜检测分数；保留集中零个真实标注实例的类别被排除在平均值之外。报告KITTI 11点和40点插值AP；40点形式是排行榜主要指标。 </p> <p> 真实标注框和预测框使用OpenPCDet 7自由度格式 <code>[x, y, z, dx, dy, dz, heading]</code>。IoU计算为两个有向BEV矩形之间的3D交并比乘以Z重叠。未应用KITTI截断/遮挡/最小高度难度过滤器，因为这些取决于对于路边LiDAR数据集不太自然的2D边界框注释。 </p> <p>该赛道的有效类别字符串在 <code>config.json</code>中列出（在<code>reference_data/</code>中提供）以及 启动工具包中的<code>submission_format.md</code>。任何带有无法识别的类别标签的预测都被丢弃。</p> <h2>3. 综合分数</h2> <p>使用每条赛道的归一化范围将每个分量最大-最小归一化为[0, 1]：</p> <pre> score_realism = mean( norm(CD), norm(MMD), norm(EMD), norm(FPD) ) (数值越小越好 → 1 - clip) score_detection = norm( AP_3d @ IoU 0.5 ) (数值越大越好 → clip) score_combined = 0.6 · score_detection + 0.4 · score_realism </pre> <p> 归一化端点在<code>config.json</code>中公开（在<code>reference_data/</code>中提供），因此本地评估器和服务器

Submission

<h1>提交格式</h1> <p>将以下所有内容打包到单个 <code>submission.zip</code> 文件中，并在<em>提交</em>标签页上传。</p> <pre> submission.zip ├── synthetic/ │ ├── 0001.bin │ ├── 0002.bin │ ├── ... │ └── 0050.bin # 恰好 50 个文件 ├── predictions.json └── declaration.pdf # 已签署的诚信声明（PDF）。也接受 declaration.txt。 </pre> <h2>synthetic/&lt;id&gt;.bin</h2> <ul> <li>恰好<strong>50</strong>个文件。</li> <li>每个文件为原始 <code>float32</code> 格式，形状 <code>N × 3</code>，按行主序排列，通道为 <code>(x, y, z)</code>（单位：米）。</li> <li>接受 <code>N × 3</code> 或 <code>N × 4</code>（xyz + 强度）格式；如果存在强度列，在评分前将被删除。</li> <li>每个文件 ≤ 1.5 MB（约 125,000 个点）。真实性在数据集级别计算：将所有 50 帧连接、掩膜至轨迹的点云范围，然后子采样至 10,000 个点（种子 1234），之后计算 CD / MMD / EMD / FPD。提交更密集的帧不会改善分数；帧顺序不重要。</li> <li>最简单的有效命名方式是 <code>0001.bin … 0050.bin</code>。</li> </ul> <h2>predictions.json</h2> <p>JSON 对象，其键为来自 <code>detection_test_frame_ids.json</code>（在起始工具包中）的帧 ID。对于每个帧 ID，必须包含一个条目，即使值为空列表也是如此。</p> <pre> { "&lt;frame_id_1&gt;": [ {"box": [x, y, z, dx, dy, dz, heading], "score": 0.97, "class": "Car"}, {"box": [...], "score": 0.81, "class": "Person"} ], "&lt;frame_id_2&gt;": [], ... } </pre> <ul> <li><code>box</code>：7 个浮点数，OpenPCDet 约定。<code>(x, y, z)</code> 是 LiDAR 框架中的框<em>中心</em>（单位：米），<code>(dx, dy, dz)</code> 是沿框局部轴的完整范围，<code>heading</code> 是围绕 <code>+Z</code> 轴的旋转角度（单位：弧度）。</li> <li><code>score</code>：置信度，范围 [0, 1]。</li> <li><code>class</code>：该轨迹的有效类别字符串之一。有效值为：<code>Person</code>、<code>Car</code>、<code>Bicycle</code>、<code>Motorcycle</code>、<code>Bus</code>、<code>Truck</code>、<code>Van</code>、<code>Unknown</code>。类别字符串匹配不区分大小写。具有无法识别的类别字符串的预测在计算 AP 前将被丢弃。</li> </ul> <h2>declaration.pdf（或 declaration.txt）</h2> <p>起始工具包附带 <code>declaration_template.pdf</code>，一份单页表单，具有预印的必需诚信声明和签名行。填写团队名称和日期，签名（用任何 PDF 工具进行数字签名，或打印 → 签名 → 扫描），另存为 <code>declaration.pdf</code>，并将其包含在每次提交中。</p> <p>如果无法轻松生成已签署的 PDF，也接受纯文本 <code>declaration.txt</code>。必需声明（逐字，不区分大小写）：</p> <blockquote> <em>I confirm that I did not train on any frame listed in <code>forbidden_frames.txt</code>, and that all submitted detections were produced by a model trained only on synthetic data I generated.</em> </blockquote> <h2>返回结果</h2> <p>评分后（通常对于有效提交耗时 < 5 分钟），您将在排行榜上看到您的排名，以及<em>详细结果</em>视图，其中包含所有组件指标，包括按类别的 AP。</p>

Rules

# 规则 ## 参赛资格 - 面向所有人开放——研究人员、学生、行业团队。 - 每支团队必须注册一个参赛者账户；不得维护多个账户。 ## 允许的做法 - 任何仿真框架或生成模型（CARLA、Helios++、OpenScene、神经辐射场、扩散模型、GAN、自定义物理引擎）。开源或闭源都可以——重要的是合成数据。 - 任何3D目标检测器架构，仅在**你的合成数据上**训练。 - 检测器训练期间应用的数据增强（旋转、缩放、翻转、真值采样、噪声）——它们作用于合成数据，不作用于禁用的真实帧。 - 使用公开真实数据集的**训练集分割**进行超参数选择或域适应，**前提是不涉及禁用帧**。（禁用列表仅包含100个预留帧，不包含整个真实训练集分割。） ## 禁止的做法 - 对`forbidden_frames.txt`中列出的**任何**100个帧进行训练、验证、超参数调优或以其他方式观察真值。这由签署声明强制执行，是该竞赛的基础诚信规则。 - 提交由在**任何**路边LiDAR数据集的真实标签上训练过的模型产生的预测。检测器必须仅限于仿真。 - 通过Codabench排行榜信号逆向工程或推断保留的真实参考帧（例如，提交设计用于泄露参考集身份的预测）。发现进行此操作的提交将被取消资格。 - 多个账户、子团队账户或注册团队间的协调。 ## 取消资格 组织者保留权利检查任何提交的合成帧和预测，以确认是否存在禁用帧泄露的证据（例如，与保留真实帧异常相似的合成帧；其分布表明可以访问保留真值的预测）。被取消资格的参赛者将从排行榜和奖金考虑中移除。 ## 奖项 每个赛道：第1名USD 500、第2名USD 300、第3名USD 200。赞助商将在开发阶段开始前公布。 ## 发布和署名 - 每支参赛团队提交一份**4–8页竞赛报告**，描述其方法。 - 倾向于不发布的团队可选择加入车间的**非发布赛道**进行提交。 - 每个赛道排名前3的团队另外被邀请提交完整论文至**下一届DriveX车间论文集赛道**。 - 竞赛组织者可发布所有提交的汇总分析（匿名处理，除非获得明确许可）。
