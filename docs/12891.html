Overview

<h1 align="center"><b>NTIRE 2026：3D内容超分辨率挑战赛</b></h1> <h2>重要日期</h2> <ul> <li>2026-01-15：训练集和验证集数据发布；<br></li> <li>2026-01-30：验证服务器上线；<br></li> <li>2026-03-10：最终测试数据发布，验证服务器关闭；<br></li> <li>2026-03-17：测试结果提交截止日期；<br></li> <li>2026-03-17：技术说明书/代码/模型提交截止日期；<br></li> <li>2026-03-19：向参赛者公布初步测试成绩；<br></li> <li>2026-03-22：挑战赛论文提交截止日期；<br></li> <li>2026-03-24：论文录用通知；<br></li> <li>2026-04-08：论文定稿提交；<br></li> <li>2026-06-18（待定）：研讨会日期；<br><br></li> </ul> <h2>赛事简介</h2> 除传统的图像和视频外，3D内容因其能够提供场景的外观与几何信息而获得了极大的普及。近年来，得益于3D生成与重建技术的进步，3D内容数量呈指数级增长。然而，当前的3D生成模型仍然存在质量相对较低的问题。对于3D重建任务而言，由于现实世界中的各种限制条件，观测到的多视图图像通常分辨率较低，最终导致重建出的3D内容质量下降。在AR/VR等应用中，提高这些3D内容的分辨率对于提供沉浸式体验以及帮助解析现实世界有着迫切需求。<br> 近年来，图像超分辨率（SR）领域取得了显著进展，用于提升图像的视觉质量。为提升3D内容质量，一种直接的方法是采用现成的图像超分辨率模型对渲染图像进行超分处理。然而，这种方法忽略了几何信息与外观信息之间紧密耦合的关系，导致多视图不一致性和闪烁伪影等问题。<br> 在本次挑战赛中，我们旨在建立3D内容超分辨率的基准评测。我们希望突出3D内容超分辨率所面临的具体挑战和研究问题。我们期待本次挑战赛能够激励学术界探索底层视觉与3D视觉的交叉领域，并最终推动AR/VR等新兴应用的技术进步。<br><br> <h2>赛事说明</h2> <a href="https://www.cvlai.net/ntire/2026/">第八届NTIRE：图像恢复与增强新趋势研讨会</a>将于2026年6月与CVPR 2026联合举办。<br> 本次挑战赛的目标是从低分辨率（LR）3D内容重建高分辨率（HR）3D内容。在开发阶段，将发布验证集。参赛者可通过将结果提交至验证服务器来评估其模型在验证集上的表现。具体而言，需要在给定相机内参和外参的条件下渲染超分辨率图像，然后提交至服务器进行在线评估。 在测试阶段，将发布测试集，其中仅包含低分辨率3D内容。挑战赛参赛者需将训练好的模型应用于低分辨率3D内容以生成超分辨率结果。随后，将这些结果提交至服务器，由组织者进行评估。<br> 本次挑战赛设有两个赛道： <ul> <li><a href="https://www.codabench.org/competitions/12891/">赛道1：双三次退化</a><br></li> 本赛道的目标是在双三次退化（Matlab中的$imresize$函数，采用双三次模式）条件下获得超分辨率3D内容。 <li><a href="https://www.codabench.org/competitions/12894/">赛道2：真实场景退化</a><br></li> 本赛道的目标是在真实场景退化条件下获得超分辨率3D内容。 </ul> <h2>组织者</h2> <ul> <li><a href="https://longguangwang.github.io/">王龙光</a>（wanglg9@mail.sysu.edu.cn），中山大学<br></li> <li><a href="http://yulanguo.me/">郭裕兰</a>（guoyulan@sysu.edu.cn），中山大学<br></li> </ul>

Data

<h1 align="center"><b>NTIRE 2026：三维内容超分辨率挑战赛</b></h1> <h2>赛道1：双立方退化</h2> <b>(1) 训练集</b><br> 本挑战赛不提供训练集，鼓励参赛者使用多样化的外部数据集，包括但不限于图像超分辨率数据集、深度图超分辨率数据集、多视角数据集和三维重建数据集，以提升三维内容的质量。<br><br> <b>(2) 验证集</b><br> 验证集包含低分辨率三维内容（使用分辨率为342×228的图像训练得到，<a href="https://www.jianguoyun.com/p/DTTUxjwQ1Zb_DRiz9JoGIAA">第1部分</a>和<a href="https://www.jianguoyun.com/p/DUH4tpMQ1Zb_DRi19JoGIAA">第2部分</a>）以及高分辨率图像/深度图（1368×912）及其对应的<a href="https://www.jianguoyun.com/p/DVZDB1gQ1Zb_DRiU9JoGIAA">相机位姿</a>。参赛者可以下载验证集，通过将其超分辨率重建后的图像/深度图与高分辨率图像/深度图进行对比，来评估所开发模型的性能。鼓励参赛者撰写论文描述其方法，并使用发布的验证集进行性能评估。<br><br> <b>(3) 测试集</b><br> 为对提交的模型进行排名，提供了包含两个三维场景的测试集。与验证集不同，测试集仅发布<a href="https://www.jianguoyun.com/p/DU4aPaYQ18WLDhjXg54GIAA">低分辨率三维内容</a>（使用分辨率为342×228的图像训练得到）和一组<a href="https://www.jianguoyun.com/p/Daju7F0Q1Zb_DRiJ9JoGIAA">相机位姿</a>。参赛者必须将模型应用于发布的低分辨率三维内容，并将给定相机位姿处的超分辨率图像/深度图（1368×912）提交至服务器。<br><br> <h2>赛道2：真实场景退化</h2> <b>(1) 训练集</b><br> 本挑战赛不提供训练集，鼓励参赛者使用多样化的外部数据集，包括但不限于图像超分辨率数据集、深度图超分辨率数据集、多视角数据集和三维重建数据集，以提升三维内容的质量。<br><br> <b>(2) 验证集</b><br> 验证集包含<a href="https://www.jianguoyun.com/p/DSNkhv0Q1Zb_DRih9JoGIAA">低分辨率三维内容</a>（使用分辨率为342×228的图像训练得到）以及高分辨率图像/深度图（1368×912）及其对应的<a href="https://www.jianguoyun.com/p/DVZDB1gQ1Zb_DRiU9JoGIAA">相机位姿</a>。参赛者可以下载验证集，通过将其超分辨率重建后的图像/深度图与高分辨率图像/深度图进行对比，来评估所开发模型的性能。鼓励参赛者撰写论文描述其方法，并使用发布的验证集进行性能评估。<br><br> <b>(3) 测试集</b><br> 为对提交的模型进行排名，提供了包含两个三维场景的测试集。与验证集不同，测试集仅发布<a href="https://www.jianguoyun.com/p/DaVm3REQ18WLDhjfg54GIAA">低分辨率三维内容</a>（使用分辨率为342×228的图像训练得到）和一组<a href="https://www.jianguoyun.com/p/Daju7F0Q1Zb_DRiJ9JoGIAA">相机位姿</a>。参赛者必须将模型应用于发布的低分辨率三维内容，并将给定相机位姿处的超分辨率图像/深度图（1368×912）提交至服务器。<br><br>
