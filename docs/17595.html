# YouTube商业内容检测与分类系统：未成年人受众合规评估 ## 系统概述 针对可能触及未成年人受众的YouTube视频中的商业内容进行检测、分类和合规风险评估，基于欧盟消费者法律框架，分四个数据访问层级架构。 --- ## 第一层：基础内容识别 ### 检测维度 - **视频元数据分析**：频道类目、观众年龄统计、内容标签 - **视频脚本扫描**：自动字幕/手动转录的商业语言模式识别 - **视觉元素识别**：品牌logo、产品展示、赞助标识 ### 输出分类 | 商业内容类型 | 识别信号 | 风险等级 | |---------|--------|--------| | 直接广告 | 明确产品推荐、定价信息 | 高 | | 原生广告 | 产品集成、品牌合作 | 中高 | | 隐性置入 | 背景品牌、角色使用产品 | 中 | | 联盟营销 | 推荐链接、折扣码 | 中高 | --- ## 第二层：产品类别与监管映射 ### 高风险产品类别（未成年人保护） - **食品饮料**：高糖/高盐、能量饮料、酒精相关 - **科技产品**：游戏、社交应用、沉浸式内容 - **时尚美容**：化妆品、整容相关服务、极端减肥产品 - **金融产品**：加密资产、赌博、在线交易平台 - **药品与补充剂**：处方药推荐、声称疗效的补充品 ### 分类规则 ``` 产品类别 → 年龄敏感度 → 欧盟指令 → 特定标记要求 ``` **示例**：能量饮料(食品) → 高(12岁以下) → 2006/114/EC(误导性广告) → 必须标注"咖啡因含量" --- ## 第三层：欧盟合规风险标记 ### 法律框架应用 #### A. 欧盟《消费者权利指令》(2011/83/EU) - **风险标记**： - 缺少清晰的商业意图披露 - 不透明的价格条款 - 无冷静期声明（适用产品） #### B. 《不公平商业惯例指令》(2005/29/EC) - **风险标记**： - 虚假/误导性声明（健康效益、性能） - 攻击性营销实践（强制购买、时间压力） - 儿童针对性的操纵策略 #### C. 《视听传媒服务指令》(2010/13/EU)修订案 - **风险标记**： - 缺少商业广告边界标记("reklame"、"Werbung"、"publicité") - 儿童节目中的插播广告违规 - 名人/影响者代言未标注 #### D. 《儿童在线隐私保护规则》(GDPR第8条+指南) - **风险标记**： - 14岁以下受众的个性化广告 - 未获得可验证的父母同意 - 行为追踪/数据收集未披露 ### 风险评分矩阵 | 合规维度 | 低风险 | 中风险 | 高风险 | |---------|-------|-------|-------| | 披露透明度 | 明确标记 | 模糊标记 | 无标记 | | 年龄针对性 | 通用内容 | 混合受众 | 明确针对儿童 | | 声称验证性 | 有证据支持 | 部分声称 | 未实质性声称 | | 数据实践 | 最小收集 | 追踪但同意 | 追踪无同意 | --- ## 第四层：报告与可视化输出 ### 检测结果架构 ```json { "video_id": "string", "commercial_content": { "detected": boolean, "types": ["native_advertising", "affiliate_marketing"], "confidence": 0.92 }, "product_classification": { "category": "energy_beverages", "risk_tier": "high", "age_sensitivity": "12+" }, "compliance_flags": { "disclosure_clarity": { "status": "non-compliant", "issue": "商业意图未标记", "regulation": "2010/13/EU", "severity": "critical" }, "misleading_claims": { "status": "flagged", "claims": ["增加体能", "改善注意力"], "evidence_status": "unsubstantiated", "regulation": "2005/29/EC", "severity": "high" }, "influencer_compliance": { "status": "non-compliant", "issue": "影响者代言未披露", "regulation": "2005/29/EC + 2010/13/EU", "severity": "high" }, "gdpr_data_practices": { "status": "warning", "issue": "链接产品的应用进行未同意追踪", "regulation": "GDPR Art.8", "severity": "medium" } }, "audience_assessment": { "likely_minor_reach": 0.78, "channel_category": "gaming", "viewer_demographics": "primarily_under_18" }, "recommendations": [ "添加明确的商业披露标记", "删除未实质性支持的健康声称", "获取影响者代言的书面披露", "审查链接产品的儿童隐私设置" ] } ``` ### 仪表板指标 - **内容风险热图**：按产品类别和合规维度 - **频道合规趋势**：时间序列违规频率 - **欧盟成员国地区映射**：国家特定法律强度权重 - **影响者网络分析**：代言关系与披露一致性 --- ## 实施考量 ### 技术栈 - **自然语言处理**：多语言商业语言检测(英语、德语、法语、西班牙语等) - **计算机视觉**：品牌识别、视觉商业标记 - **图知识库**：产品-类别-法规映射 ### 局限性与透明度 - 文化差异：商业实践的地区规范差异 - 假阳性风险：讽刺/教育性内容误分类 - 法律滞后：新兴平台实践的监管覆盖不足 --- ## 参考法律工具 | 指令 | 关键条款 | 实施成员国差异 | |-----|--------|------------| | 2010/13/EU(AVMSD) | 第9条:广告披露 | 德国严格;南欧执法宽松 | | 2005/29/EC | 附件I:禁止实践 | 一致性高 | | GDPR | 第8条:儿童同意 | 比利时(7岁);其他国家(16岁) | 此系统设计可扩展至TikTok、Instagram等平台的适应性修改。

Overview

# ChildSafeAds — 儿童面向YouTube视频中的商业内容 **一项共同任务，在[NLLP](https://nllpw.org) @ EMNLP 2026举行。** 想象你在一个负责监督到达视频平台未成年人的商业内容的机构工作。你如何构建监控系统，以及在每个数据访问和成本级别，它能达到什么效果？ 影响者营销到达儿童和青少年在YouTube上广泛存在，且经常未披露。在平台规模上评估它需要自动化支持，但负责任地进行此操作意味着分类正在销售的内容、对其进行分类，并推理其引发的广告法律问题。本任务在真实数据上将这三个方面结合在一起。 ## 数据 **3,360个实例**：训练集2,353 / 开发集504 / 测试集503，**频道不相交**（任何频道不在多个分割中出现）。每个实例是一个赞助片段，通过SponsorBlock社区验证，在精心策划的可能到达大量青少年受众的频道上，配有其描述链接到的产品页面。 字段按**四个访问级别按收集成本排序**分组：片段文本记录、包括YouTube自有付费推广标志的视频元数据、频道上下文，以及爬取的产品页面。纯文本记录系统使用一个字段；每个进一步级别在规模上获取需要更多成本。 ## 子任务 | | 任务 | 输出 | |---|---|---| | **ST1** | 商业类型 | 一个标签（EU消费者权益指令合同类型） | | **ST2** | 产品类别 | 一个或多个标签 | | **ST3** | 合规风险标志 | 一个或多个标志，基于EU消费者法（UCPD、AVMSD、DSA、CRD） | 可参与任何子集。定义在随数据提供的`labels_taxonomy.md`中；每个标志的法律依据在`legal_provisions.json`中作为引用和说明，而非法定文本。 数据集给出两点且系统不应重新评估：频道面向儿童，片段为商业内容。问题是销售的是什么以及它引发什么问题。 ## 我们实际在询问的内容 准确度在排行榜上评分，但有趣的问题是设计问题：**每个额外的数据级别能买到什么，成本是否值得？** 因此每个提交都记录其使用了哪些数据级别，这出现在排行榜上分数旁边，所以结果读作*给定数据成本下的准确度*。除了那个下拉菜单外，我们高度鼓励一份简短的**系统设计报告**，描述你权衡的权衡。这不是完整论文，这是本任务最有趣的发现可能存在的地方。 **额外赛道**邀请团队进一步自行收集平台外目标数据（商店、服务条款、应用程序），从我们提供的出站链接开始。不计分，非常欢迎在报告中呈现。 ## 入门 1. 注册（需要批准；注册即表示接受数据使用条款）。 2. 从"参与"标签下载**公开数据**和**入门工具包**。 3. 运行多数基线以生成有效提交、用包含的格式检查器检查，然后提交。 见**数据**、**评估**和**条款**页面了解具体信息。

# 数据 ## 获取方式 数据集附加到此竞赛的每个阶段。请进入**参赛**选项卡并下载**公开数据**： | 阶段 | 文件 | 内容 | |------|------|------| | 开发阶段 | `public_data_dev.zip` | `train.jsonl`（2,353条）和`dev.jsonl`（504条），均已标注，附带文档 | | 评估阶段 | `public_data_test.zip` | `test.jsonl`（503条），未标注，附带文档 | 测试输入在评估阶段开启时发布。同一选项卡上的**启动工具包**包含该格式的加载器、提交格式检查器、多数基线和有效样本提交。 每个压缩包还包含`README.md`（数据集说明卡）、`labels_taxonomy.md`（完整标签定义、严重程度、直接劝说测试、额外任务）和`legal_provisions.json`。 ## 格式 数据集划分采用**渠道隔离**方式：任何渠道仅出现在一个数据集中。JSONL文件的每一行代表一个实例，字段分为四个访问级别，按收集成本排序，以便系统根据需要使用相应的数据。 | 级别 | 字段 | 内容 | 收集成本 | |------|------|------|---------| | 1 | `transcript` | `text`、`segment_start`、`segment_end` | 最低；可扩展至整个平台 | | 2 | `video_context` | `videoID`、`title`、`description`、`official_disclosure` | 每个视频一次元数据调用 | | 3 | `channel_context` | `channelID`、`channel_name` | 一次频道查询 | | 4 | `product_page` | `raw_url`、`resolved_url`、`page_title`、`text` | 爬取出站链接；部分页面已失效或阻止自动访问 | `official_disclosure`是YouTube自身的"包含付费推广"标签：`"true"`、`"false"`或当无法确定时为`""`。 `train.jsonl`和`dev.jsonl`包含`labels`块；`test.jsonl`不包含。 ```json "labels": { "st1": "digital_content_or_services", "st2": ["apps", "gambling_adjacent"], "st3": ["undisclosed_advertising"], "st3_evidence": [{"flag": "undisclosed_advertising", "quote": "verbatim span from this instance's text"}] } ``` 每个`st3_evidence`引文来自该实例本身的转录文本、描述或产品页面的逐字段选。无法匹配到来源的引文被省略，因此一个标志可能不带任何证据条目。 ## 标签和法律依据 `labels_taxonomy.md`提供完整定义。简言之：ST1是单标签（购买者获得的内容）、ST2是多标签（被销售的内容）、ST3是多标签合规标志，其中`no_flag`和`insufficient_context`各自独立。 `legal_provisions.json`将每个标志映射到为其提供依据的欧盟法律工具和条款，并附带严重程度属性和各条款要求的说明。它包含**引文和注释，而非法定条文**，涵盖本版本中标志后的条款而非整个欧盟广告法。标识符可根据EUR-Lex和委员会指南解析，如需检索更完整的法律材料；这样做是否改进标志预测是我们希望报告探讨的一个开放问题。 ## 来源和策划 频道经过策划，合理覆盖重要的青少年受众：使用基于频道描述、视频标题和元数据的自动分类器，随后进行人工验证的排除审查。这对每个频道的准确性无法保证，但意味着**系统无需自行评估受众**；将"面向儿童"视为数据集级属性。 标签经过自动注释，并进行人工验证和法律校准。部分合规标志仍在法律审查中，可能在补丁版本中细化；任何变更将在此竞赛中公布。人工标注的校准示例将与评估阶段一同发布。 ## 许可证 该数据集源自[SponsorBlock](https://sponsor.ajay.app/database)数据库，采用**CC BY-NC-SA 4.0**许可。根据该许可的共享条款，衍生标签、实例结构
